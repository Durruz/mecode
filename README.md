# Mecode

Десктопная среда на Rust, где **Claude Code и Codex работают в одном чате**: видят сообщения друг друга,
отвечают друг другу и вместе делают задачи в папке вашего проекта.

## Как это работает

- Агенты запускаются через установленные `claude` и `codex` CLI, по вашим подпискам. API-ключи не нужны.
- Каждый агент ведёт свою сессию и в каждый ход получает новые сообщения чата с подписью автора.
- Кому отвечать, решают упоминания: `@claude`, `@codex`, `@all`. Без упоминания сообщение уходит тому,
  кто выбран в переключателе «Всем / Claude / Codex».
- Агент, упомянувший `@другого`, будит его. Подряд без вашего участия — не больше 8 ходов, потом пауза.
- Чаты хранятся в `%APPDATA%\mecode`, настройки — в `%APPDATA%\mecode\config.json`.

## Запуск

Нужны: [Rust](https://rustup.rs), установленные и авторизованные `claude` и `codex`.

```sh
# Десктопное приложение (Tauri)
cargo run --manifest-path desktop/Cargo.toml

# Или ядро с простой страницей в браузере
cargo run -p mecode-server
```

## Устройство

| Папка | Что внутри |
|---|---|
| `crates/mecode-core` | Оркестратор чата, запуск агентов, разбор `@упоминаний`, хранение |
| `crates/mecode-server` | HTTP + WebSocket API (только 127.0.0.1), бинарник `mecode` |
| `desktop` | Tauri-приложение и интерфейс |
| `docs/API.md` | Контракт API между ядром и интерфейсом |

Тесты: `cargo test --workspace`.

## Безопасность

Агенты выполняют команды на вашем компьютере. Сервер слушает только `127.0.0.1` и отклоняет запросы
с посторонних сайтов. По умолчанию Claude работает в режиме `acceptEdits`, Codex — `workspace-write`
(пишет только в папке проекта). Режимы меняются в `config.json`.
